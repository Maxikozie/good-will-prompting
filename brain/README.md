# Brain — shared team knowledge

Everything we know about the challenge, in one place. Agents: read this folder before building anything.

## TL;DR
**SD Worx challenge:** *How might we turn fragmented organisational knowledge into a trusted shared resource?*
Build a **focused** proof of concept that makes knowledge easier to **FIND**, **TRUST** and **SHARE**.
They explicitly do **not** want "a SharePoint with a search function" or "another AI agent". They already have both and still have the problem.

**Scoring note:** 10% of the score is security, measured with Aikido (see [judging.md](judging.md)).
